## 1. What it is
A **cockpit for running many coding agents from one interface** — as a **TUI** or a **Web UI** (so you can reach running sessions from mobile). Supports a broad set of agents: Claude Code, OpenCode, Codex CLI, Gemini CLI, Copilot CLI, Factory Droid, Mistral Vibe, Pi.dev.

## 2. Quotes (verbatim — attributed)
- Repo description: *"Manage multiple Claude Code, OpenCode agents from either TUI or Web for easy access on mobile."*

## 3. Features
- **TUI and Web** front-ends over the same agents.
- **Mobile access** to live agent sessions via the web UI.
- **Broad agent coverage** (8+ CLIs/agents).
- **Rust**, MIT-licensed.

## 4. Choose / avoid
- **Choose it when** you want one cockpit (terminal or browser) over many agents, with mobile reach.
- **Avoid when** you prefer a native desktop app (T3 Code, cmux) or a single-agent flow.
