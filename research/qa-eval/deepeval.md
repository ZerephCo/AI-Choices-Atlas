## 1. What it is
"The LLM Evaluation Framework." A Pytest-like framework to unit-test LLM outputs against research-backed metrics, locally or in CI.

## 2. Quotes (verbatim — attributed)
- Repo desc: *"The LLM Evaluation Framework."*

## 3. Features
- **Pytest-like** test cases for LLM apps.
- **40+ research-backed metrics** (G-Eval, faithfulness, answer relevancy, hallucination, RAGAS, bias, toxicity).
- Datasets/benchmarks; component-level evals; **DeepTeam** red-teaming.
- Self-host or the Confident AI platform.

## 4. What it is NOT / limitations
- Code-first (Python); not a declarative YAML tool (promptfoo) or a tracing platform (Langfuse).

## 5. Roadmap
- **Was:** 2023-08 (Confident AI).
- **Now (2026):** ⭐17k; Apache-2.0; 40+ metrics + Pytest.
- **Ahead:** more metrics; agent evals.

## 6. Positioning
- **DeepEval** — code-first, metric-rich LLM evals in a Python/Pytest workflow.
- vs promptfoo (declarative + red-team), Langfuse/Phoenix (observability), Playwright (browser).
