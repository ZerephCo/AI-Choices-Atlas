## 1. What it is
A **proprietary AI-native IDE** (a VS Code–based editor) built around the **Cascade** agent — multi-file edits, terminal actions, and tool use — plus fast **Tab** autocomplete. Formerly **Codeium**, then **Windsurf**; **acquired by Cognition (2025-07-14)** and **rebranded Devin Desktop (announced 2026-06-02)** — per Cognition's announcement, *"The next generation of Windsurf, built around Devin Cloud, the Agent Command Center"*. The docs note the transition: *"the package is now called `devin-desktop`."*

## 2. Access (why it's in the atlas) — re-verified 2026-08-19, partially
- Cognition's **2026-04-14 self-serve relaunch** retired older tiers and introduced **Free, Pro, Max, Teams, Enterprise** plans; docs state users *"can sign up for free."*
- ⚠️ **Unverified today:** the exact Free-plan contents (Tab limits, credits) and whether a credit card is required — devin.ai's pricing page sits behind bot protection (HTTP 429 / Vercel checkpoint), so this re-check could not read it. The 2026-07 verification (unlimited Tab + ~25 credits/mo, no CC) is retained as the last-known-good detail; re-verify before relying on it.

## 3. Features
- **Cascade agent** (multi-file, terminal, tools) in an AI-native IDE.
- **Tab autocomplete**; a Free plan exists in the current lineup — its exact limits (Tab, credits) are unverified as of 2026-08-19 (see §2).
- Plugins for other editors; enterprise options.

## 4. Choose / avoid
- **Choose it when** you want the polished proprietary agentic-IDE lineage now continued as Devin Desktop, and Cognition's current free-plan terms (verify them) fit your use.
- **Avoid when** you need open/local tooling (Continue), heavy daily use beyond free credits, or verified-stable pricing.
- Compare with Cursor (§1.2, also free-tier) and open Continue/Void (§1.2).
