## 1. What it was
"Roo Code gives you a whole dev team of AI agents in your code editor." An open-source VS Code coding agent that began as a **Cline fork** and differentiated with **customizable Modes** (Code, Architect, Ask, Debug + user-defined Custom Modes).

## 2. Quotes (verbatim, from docs — attributed)
- Tagline: *"Your AI-Powered Dev Team, Right in Your Editor."*
- Modes: *"Adapt with Modes: Code, Architect, Ask, Debug, and Custom Modes."*
- Custom modes: *"build specialized modes for your team or workflow."*
- Disclaimer: *"does not make any representations or warranties regarding any code, models, or other tools."*

## 3. What it did (features, past)
- **Custom Modes** — Code / Architect / Ask / Debug + user-defined modes (its main differentiator vs Cline).
- MCP server support; browser + terminal; `@`-mention context; code actions; custom instructions.
- BYOK across any provider incl. local.

## 4. ⚰️ Sunset status (VERIFIED)
- **VS Code extension shut down May 15, 2026**; GitHub repo **archived** (`archived=true`, frozen at 2026-05-15).
- Docs/README now carry a shutdown warning.
- **Migration paths:** **ZooCode** (community fork) and **Cline** (original source).
- Marketplace listing remains as a **legacy** build (v3.54.0) but is unmaintained.
- Verification: GitHub API `archived=True`, `pushed_at=2026-05-15`; docs.roocode.com + multiple 2026 reviews confirm shutdown.

## 5. What it is NOT / limitations
- Not maintained (archived); not safe for new adoption.
- Legacy marketplace build is unmaintained.
- Coding host ≠ merge authority.

## 6. Roadmap
- **Was:** forked from Cline (Oct 2024); pushed mode-based customization; ⭐24k.
- **Now (2026):** ⚰️ shut down (May 15, 2026); repo archived; community continues via ZooCode.
- **Ahead:** no vendor roadmap; ZooCode fork carries the lineage.

## 7. Positioning
- **Roo Code** — historically the "more modes / more customization" Cline fork; now discontinued.
- For active alternatives: **ZooCode** (community fork), **Cline** (original), Cursor (proprietary IDE).
