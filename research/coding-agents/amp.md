## 1. What it is
Sourcegraph's **agentic coding tool** — a CLI plus a VS Code extension that runs multi-step coding work. It qualifies for this atlas via a **free, ad-supported tier** (no hard token caps) that needs no upfront payment; a paid **Smart Mode** adds zero-data-sharing, deeper reasoning ("Oracle Mode"), and priority routing on a pay-as-you-go basis.

## 2. Access (why it's in the atlas)
- **Free tier**, ad-supported: Amp Tab autocomplete + the core agent, **no hard token caps**; sponsored suggestions may appear in non-code contexts.
- **Smart Mode** (paid, pay-as-you-go): zero data sharing, Oracle Mode, priority routing, higher subagent throughput.

## 3. Features
- **CLI + VS Code** agentic coding.
- **No hard token caps** on the free agent.
- **Thread sharing**; subagent parallelism (throughput gated on paid).

## 4. Choose / avoid
- **Choose it when** you want a capable agent with a real free, no-hard-cap tier and don't mind ads in non-code contexts.
- **Avoid when** you need zero data-sharing (paid) or a fully open/local tool.
- Compare with Claude Code / Codex CLI (§1.1) and open Continue (§1.2).
