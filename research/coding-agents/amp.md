## 1. What it is
Sourcegraph's **agentic coding tool** — a CLI plus a VS Code extension that runs multi-step coding work. It qualifies for this atlas via a **free tier** that needs no upfront payment. Amp Free launched **ad-supported** (2025-10-15: *"It's free of charge and supported by ads"*), then dropped the training-data opt-in (*"Amp Free no longer requires you to opt into sharing your data for training"*), and later dropped ads entirely (*"Amp Free no longer has ads"*).

## 2. Access (why it's in the atlas) — re-verified 2026-08-19
- **Amp Free**: now **ad-free**, for interactive editor/CLI use; *"There are some rate limits."* (The earlier "no hard token caps (ad-supported)" description is obsolete.)
- **Paid**: a monthly subscription that *"includes agent and orbs usage"* plus pay-as-you-go credits; enterprise usage priced higher. The former "Smart Mode" branding no longer appears in the current manual — treat old Smart Mode/Oracle descriptions as historical.

## 3. Features
- **CLI + VS Code** agentic coding.
- **Thread sharing**; **orbs** (hosted agent sandboxes, multiple sizes); **Puck** realtime-voice agent control (2026-08); global plugins + skills; remote MCP servers.

## 4. Choose / avoid
- **Choose it when** you want a capable agent with a real free (now ad-free) tier for interactive use.
- **Avoid when** you need throughput beyond free rate limits, verified data-handling terms, or a fully open/local tool.
- Compare with Claude Code / Codex CLI (§1.1) and open Continue (§1.2).
