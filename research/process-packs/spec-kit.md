## 1. What it is
"Toolkit to help you get started with Spec-Driven Development." GitHub's SDD toolkit: write an executable spec, then the agent generates a plan, tasks, and implementation.

## 2. Quotes (verbatim — attributed)
- Repo desc: *"💫 Toolkit to help you get started with Spec-Driven Development."*

## 3. Features
- **`specify` CLI** scaffolds the workflow.
- Phases: `/specify` → `/plan` → `/tasks` → `/implement` slash-commands.
- **Constitution** (project principles) that constrains generation.
- **Multi-agent** — Claude Code, Copilot, Cursor, Gemini CLI, etc.

## 4. What it is NOT / limitations
- Structured/spec-first (overhead for tiny tasks).
- A process kit, not a runtime.
