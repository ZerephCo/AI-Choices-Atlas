## 1. What it is
A **production-grade skills pack for AI coding agents**: 24 structured, Markdown-defined workflows ("skills") that make an agent follow senior-engineer best practices across the whole lifecycle — **Define → Plan → Build → Verify → Review → Ship**. Skills are step-by-step processes with checkpoints and evidence requirements, not generic prompts; they layer on top of a coding host (§1).

## 2. Quotes (verbatim — attributed)
- Repo description: *"Production-grade engineering skills for AI coding agents."*

## 3. Features
- **24 skills** (23 domain-specific + 1 meta) spanning the full lifecycle.
- **8 slash commands** (`/spec`, `/plan`, `/build`, `/test`, `/review`, `/webperf`, `/code-simplify`, `/ship`).
- **`/build auto`** autonomous mode with human verification gates.
- **4 specialist personas** (code-reviewer, test-engineer, security-auditor, web-performance-auditor).
- **7 reference checklists** + anti-rationalization tables + evidence requirements per skill.
- **Broad agent support** (Claude Code, Cursor, Cline, Copilot, Codex, Gemini CLI, Windsurf, OpenCode, Kiro, and any system-prompt agent).

## 4. Choose / avoid
- **Choose it when** you want a broad, disciplined skills pack enforcing senior-engineer practices end-to-end.
- **Avoid when** you want a runtime/agent (this is instruction content on a host, §1) or a narrower spec-only kit (§13.1).
- Compare with anthropics-skills and Superpowers (§13.3); pairs with a coding host (§1) or loop (§5).
